# 📊 India General Election Result Analysis 2024 (SQL Project)

## 📌 Project Overview
An end-to-end relational database analysis on the **India General Election 2024** dataset. This project explores constituency metrics, alliance seat breakdowns (NDA vs I.N.D.I.A), EVM vs postal vote distributions, and winning margins using SQL aggregations and complex joins.

---

## 🗂️ Database Schema & Data Model
The project utilizes a 5-table relational database model:
- `constituencywise_details`
- `constituencywise_results`
- `partywise_results`
- `statewise_results`
- `states`

---

## 🔍 Key Business Questions Answered
1. **Winning Candidates & Margins:** Victory margins for candidates across specific states and constituencies.
2. **EVM vs. Postal Vote Distribution:** Analysis of EVM vs postal vote ratios.
3. **Alliance Seat Tally:** Seat distribution calculation across major political alliances (NDA, I.N.D.I.A, and Others).
4. **Top EVM Performers:** Identification of top 10 candidates with maximum EVM votes nationwide.
5. **Winner vs. Runner-Up Pairings:** Comprehensive state-by-state head-to-head comparison.

---

## 🛠️ Tech Stack & Skills Demonstrated
- **Database:** PostgreSQL / MySQL
- **SQL Concepts:** Complex Joins, Aggregations, GROUP BY, Window Functions, ERD Schema Mapping.
